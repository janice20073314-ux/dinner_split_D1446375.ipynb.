## 問題回答

### 1. 為什麼 "4" 要先轉成數字？
"4" 在 Python 中是字串型別 (`str`)，而數字 4 則是整數型別 (`int`)。程式需要將餐費總額除以人數來計算每人分攤費用，Python 無法直接將數值除以字串，因此必須先用 `int()` 將字串轉為整數才能進行數學運算。此外，若用字串相加（如 `"4" + "1"`）會變成字串串接（得到 `"41"`），而不是數值加總。

### 2. 如果先扣折價券，再計算服務費，第一組總額為何會變成 1,210 元？
如果先扣除折價券（1,200 - 100 = 1,100 元），再以 1,100 元來計算 10% 的服務費，服務費會變成 1,100 × 0.10 = 110 元。這樣算出來的應付總額為 1,100 + 110 = 1,210 元（比原本以原始餐費計算的 1,220 元少 10 元）。因為題目規定服務費需以原始餐費基準計算，故應依原本的順序執行。
